📌 PROBLEM
─────────
Your login and signup pages don't work because Supabase has email rate 
limiting enabled by default, which blocks new signups and login attempts.

✅ SOLUTION
──────────
Disable rate limiting in Supabase Dashboard (3 clicks, 5 minutes).

🚀 QUICK START (Follow These Steps)
───────────────────────────────────

Step 1: Open Supabase Dashboard
   → https://supabase.com/dashboard

Step 2: Select Your Project
   → Click: OriginLab-ai-app

Step 3: Go to Authentication Settings
   → Left Menu: Authentication
   → Click: Providers tab
   → Find: Email provider

Step 4: Disable Email Rate Limiting
   → Find: "Email Rate Limiting" toggle
   → Action: Toggle it OFF (should be gray/left)
   → Click: Save button

Step 5: Disable Email Verification (Optional but Recommended)
   → Still in Email settings
   → Find: "Confirm email" toggle
   → Action: Toggle it OFF
   → Click: Save button

✅ VERIFY IT WORKS
──────────────────

Test 1: Check Status
   → Open: http://localhost:3000/auth/test
   → You should see login status displayed

Test 2: Sign Up
   → Go to: http://localhost:3000/auth/sign-up
   → Email: test@example.com
   → Password: Test123!@#
   → Repeat: Test123!@#
   → Click: Sign up
   → Expected: Success message ✅

Test 3: Log In
   → Go to: http://localhost:3000/auth/login
   → Email: test@example.com
   → Password: Test123!@#
   → Click: Login
   → Expected: Logs in successfully ✅

🎉 DONE!
────────
Your authentication is now fully functional!

🔧 TROUBLESHOOTING
──────────────────

Error: "Invalid credentials"
   → Make sure you signed up first (do Test 2 above)
   → Check Supabase Dashboard → Authentication → Users
   → Verify the user exists

Error: "Too many requests"
   → Email rate limiting is still enabled
   → Go back to Step 4 above and make sure toggle is OFF
   → Click Save again
   → Wait 1 minute and try again

Error: "Confirm email" required
   → "Confirm email" toggle is still ON
   → Go back to Step 5 above and toggle it OFF
   → Click Save
