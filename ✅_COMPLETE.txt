🔍 WHAT YOU NEED TO DO
───────────────────────

Required (to enable authentication):
  1. Go to Supabase Dashboard
  2. Select OriginLab-ai-app project
  3. Authentication → Providers → Email
  4. Toggle OFF: "Email Rate Limiting"
  5. Toggle OFF: "Confirm email" (optional but recommended)
  6. Click Save

Optional (after authentication works):
  1. Run database migrations
  2. Create user profile pages
  3. Set up email notifications

Time required: ~5 minutes to enable, ~15 minutes to fully understand
